# Tech Stacks
The website is made using the REACT framework, specifically Next.JS.

In combination with REACT is TailwindCSS, which allows in-line CSS when working with HTML.

Therefore, a component is made up of only one JavaScript file as REACT lets us work with JavaScript and HTML in the same file.

The backend is made using Python, specifically the Django framework. This is a REST API system that I used to pass information generated by my ML models to the website. To read about the model I developed, please refer to the next blog.

The backend is hosted on PythonAnywhere, and the frontend is hosted on Netlify. I chose these because they have quick deployment processes.
